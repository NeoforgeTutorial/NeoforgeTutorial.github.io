# 网络

服务端与客户端之间的通信，是模组功能顺利运行的基础。

网络通信主要有两个目标：

1. 确保客户端看到的内容与服务端保持同步
    - 坐标 (X, Y, Z) 处的花刚刚生长
1. 让客户端能够通知服务端玩家触发了某种变化
    - 玩家按下了某个按键

实现这些目标最常见的方式，是在客户端与服务端之间传递消息。这些消息通常具有固定结构，按特定方式组织数据，以便更轻松地发送和接收。

NeoForge 提供了一套主要用于简化通信的技术，它大体建立在 [netty] 之上。使用这套技术时，需要监听 `RegisterPayloadHandlersEvent` 事件，然后向注册器注册特定类型的[载荷][payloads]、其读取器和处理函数。

[netty]: https://netty.io "Netty 网站"
[payloads]: payload.md "注册自定义载荷"
